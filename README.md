# nano-ui-components

Standalone Angular UI components published as the `nano-ui-components` package.

```ts
import { NanoButtonComponent, NanoTextInputComponent } from 'nano-ui-components';
```

Import `nano-ui-components/themes.css` in the consuming application's global stylesheet to load the default dark theme and the light theme tokens. The light theme is selected by setting `data-theme="light"` on the document root.
